# 全局字体

用户提供的阿里巴巴普惠体 3.0 原始 WOFF2 文件，文件内容不作修改。

`fonts.css` 仅引用界面需要的 Regular（400）、Medium（500）、SemiBold（600），共 16,207,176 字节（约 15.46 MiB）。Bold 保留在源目录，未被引用，不进入 Vite 构建输出。字体本地加载，缺字沿用系统字体回退，技术标识保留等宽字体。

这些文件已经使用 WOFF2 压缩。字形子集可进一步减小体积，但裁掉的字符需要系统字体回退，动态标题、作者和转写文案不能只按固定界面文字裁剪。本次不做子集、拆分或格式转换，不新增字体处理依赖。
