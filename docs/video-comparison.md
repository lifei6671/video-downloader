# 跨视频对比工作区（WB-307）

## 范围与交互

知识库勾选 2～4 个视频后点击“对比所选”。工作区按资产 ID 固定分栏，同一维度横向对齐；窄窗口仅对比区域横向滚动。返回保留列表筛选和选择。没有新增服务、依赖或 AI 调用。

每栏提供原文首段、文案结构、制作手法拆解和片段。默认选择最新识别原文（无识别原文时选择最新整理稿）、最近更新的两类结构化拆解及最近五个片段；可切换保存版本，最多选择八个片段。自由文本旧笔记不被猜测成结构化拆解。没有文案、拆解、片段或结构字段为空时显示“未知”，读取失败显示错误并保留已读内容，不冒充资料已删除。

原文首段取首个非空行的前 500 个 Unicode 标量；文案六字段各取前 500 个，拆解正文摘录最多 2000 个，片段引用文案最多 500 个。它们用于并排比较和保留快照，不代表已经看完视频或听过音频；来源入口可打开对应完整文案、拆解摘录或范围播放器。AI 来源展示原记录的模型及人工修订标识。

比较笔记含标题和 1～24 条结论，每条至少选择一项来源。勾选时复制当前栏的来源快照与 pin；切换栏内版本、刷新来源或编辑结论，不改变此前结论的引用。要改用新来源，须取消该项再勾选。保存到所选视频之一的一篇 `comparison` 笔记，其他视频不复制笔记。保存后可在归属视频的笔记列表打开，编辑标题与结论，原引用保持不变。失败保留草稿，导航沿用保存 / 放弃 / 继续编辑保护；提交成功但回读失败明确显示已保存，不再次创建。

## 命令与来源契约

| Tauri 命令 | 入参 / 返回 |
| --- | --- |
| `get_library_comparison_source` | `pin` → `ComparisonSource`，只读取所声明资产的资料 |
| `create_library_comparison` | `assetId, input:{title,asset_ids,points:[{text,sources:ComparisonPin[]}]}` → note ID |
| `edit_library_comparison` | `assetId,noteId,input:{title,point_texts},expectedRevision` → CAS 更新 |

`ComparisonPin` 包含 `asset_id`、可空 `document_id`、可空 `copywriting / technique:{id,revision}` 和 `clip_ids`。文案 ID 对应不可变版本；`None` 是明确未知，不在保存时换成其他资料。Rust 重新解析 pin，验证资产归属、拆解类型 / 修订号及片段身份，从实际记录生成快照和正文；不接受前端直接提交来源正文。某拆解已更新时返回 `COMPARISON_SOURCE_CHANGED`，整篇不写入。

来源快照保存资产 ID / 当时标题、文案 ID / 版本 / 首段、拆解 ID / 修订号 / 来源 / 模型 / 人工修订 / 摘录 / 六字段，以及片段 ID / 文件 ID / 起止 / 文案引用。没有持久化绝对媒体路径、凭据或当前文件可用状态。每条来源属于比较成员，成员及结论内来源不重复。文案 `Citation` 仅由本来源实际原文与片段引用生成并去重，不挪用另一篇拆解的引用。

来源对话框以资产和具体 ID 读取。文案检查版本；拆解始终展示保存时摘录，当前修订更高时标明新旧修订；片段重新检查文件和起止，删除 / 缺失 / 变化明确反馈，不关联其他视频。关闭对话框忽略迟到读取并释放播放器。拆解摘录保留当时内容，不自动重算旧结论。

比较记录由人工创建，来源拆解可以是人工或 AI；这两个归属分别保存。原 MCP 七项只读工具和 Resources 白名单不变，`get_note` 通过既有正文、revision 和文案 citations 消费比较，未开放本批 Tauri 写入或媒体接口。

## 持久化与恢复

schema **v8** 在 `asset_notes` 之外新增 `note_comparisons(note_id,data)`，外键随笔记级联删除；创建、正文投影、修订和结构保存使用同一事务。原文、拆解和片段仍由各自领域管理，不建设第二套资产系统。自由正文编辑拒绝比较记录，防止正文与结构失配。

从 v1～v7 升级前沿用 `VACUUM INTO` 一致性备份和事务迁移。WB-307 首次引入逻辑包 v6；当前 WB-310 writer **v9**，reader **v1～v9**，另保存[自己的选题与草稿](ideas-and-drafts.md)及[研究专题](research-topics.md)关系；旧版本包夹带 comparison 字段拒绝。恢复验证所有成员与归属、正文投影、citations、文案不可变版本、拆解身份与来源、修订合法性、快照字段形状和片段文件 / 范围。当前拆解修订可高于保存修订；保留合法旧快照，不把最新内容当作旧版。相同修订要求内容匹配。现有数据没有拆解全文历史表，无法从当前修订重建已被替换的旧全文，快照是该次比较的保留记录。

已删除片段可保留历史快照，但文件记录仍须属于同一资产，文案版本和引用仍须可验证。媒体可选备份；不含媒体时保留笔记结构与引用，播放按当前文件状态反馈。恢复失败不发布半库。

## 验证边界

Rust 定向测试覆盖错资产、错文案 / 拆解 / 片段、过期修订、重复成员、未知、Unicode、事务 / CAS、schema 迁移、两轮含 / 不含媒体恢复、旧包字段夹带和畸形历史快照。浏览器分别验证工作区、草稿和来源播放器；Windows 原生验证生产命令、SQLite、来源打开和空闲重启。macOS Intel / Apple Silicon 继续待验收。实际结果见[第二十五批记录](workbench-knowledge-base-validation.md#第二十五批wb-307-跨视频对比工作区)。
