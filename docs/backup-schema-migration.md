# 数据库单次升级

## 基线与版本

以 `master` 提交 `2d32959a7d8367aff57c6a1d962ea048afbc4ea0` 的现有 SQLite 结构为升级起点。该结构包含下载任务、提交意图、暂存记录、解析缓存、设置和文案；本分支新增的结构统一为一个发布版本，使用 `backup_schema.version=1` 记录。

从 master 升级只执行一次事务，直接得到本分支最终结构，不再经过开发期间的 v5/v6/v7/v8/v9 分段迁移。新建数据库也直接创建同一套最终结构。SQL 按资产、同步、Telegram、显示投影和历史登记拆分文件仅为组织代码，不代表多个升级版本。

## 一次升级的内容

- 资产、文件、封面、文案、同步空间、空间成员、远端状态及冲突记录。
- 备份队列、操作显示投影及其维护触发器、独立上传捕获、导入回执。
- 按空间保存的删除隐藏状态、历史登记失效触发器、反向索引及恢复查询索引。
- Telegram 账号绑定、发送证据、冷却状态、频道信息及消息索引。
- 下载并发设置约束从 1–3 调整为 1–5；保留用户已有选择、目录和文件名模板，新设置默认值为 3。

原有任务、解析缓存、平台配置及文案保留。旧 `tdl_settings` 表原样保留但不再使用；新库不创建该表。数据库迁移不读取真实会话、不联网、不修改远端协议，也不主动补录历史下载。

## 原子性与备份

`Core::open` 取得原有应用实例锁后，先调用 `schema_migration::prepare` 识别数据库。已有 master 数据库在任何结构或缓存写入前，通过 rusqlite 的 SQLite 原生 backup API 保存同目录完整快照，包含已提交 WAL 页：

```text
yingqu.sqlite.before-backup-v0-<UUID>.sqlite
```

文件名中的 v0 表示 master 基线尚未使用本分支的版本表，不是新增的迁移阶段。全新空库无需快照。快照先写私有临时文件、同步落盘，再以不覆盖方式保存；备份失败则不开始升级。

桌面基础表兼容初始化、设置约束变更、全部新表/索引/触发器、设备身份和版本标记处于同一事务中。外键检查通过后才写入最终版本号并提交，任何一步失败均整体回滚，升级前快照保留。不会关闭外键或使用 `writable_schema`。再次启动保留现有设备身份和版本，不重复备份或重建数据。

文案中断恢复在结构事务提交后执行，沿用原有恢复事务；备份操作仍按既有规则处理不确定的运行中状态。结构升级不代表任务在远端已经成功。

## 已运行本分支的数据库

已具有最终结构的开发版 v9 数据库，在核对关键表结构并创建完整快照后，直接归并版本标记。空间、开关、资料、捕获正文、操作身份和 Telegram 发送回执保持；不重放旧的删列、归档、隐藏状态或捕获搬移逻辑。

不再支持开发期间未完成的中间结构自动升级。旧开发 v1 与合并版 v1 的关键表布局不同，不能仅凭相同数字认为兼容；未知版本或关键表缺失会在启动写入前明确失败，不能手改版本号绕过检查。本次开发不会修改正在运行的本机数据库。

恢复快照前必须完全退出应用，并使用匹配该快照结构的程序；不要覆盖仍打开或有未处理 WAL 的数据库。

## 运行期数据规则

`asset_hidden_history` 保存主动移除历史的全局标记；`asset_deletion_hidden_history(space_id,asset_id)` 保存按空间删除的隐藏状态，其他有效成员仍可显示和恢复。

操作显示投影由同事务触发器维护，不作为恢复发送或认定上传成功的依据。不可变封面和文案捕获保存在 `backup_operation_captures`；上传发布确认或旧操作被真正终结后回收正文，未完成、取消、失败和未知结果继续保留恢复证据。

`backup_import_receipts` 比较远端记录与版本、本地版本及待上传状态，避免重复导入；共享资产被另一空间重写时失效相关回执。回执不作为备份成功、删除归属或完整性的证据。

## 验证

`cargo test --locked --manifest-path src-tauri/Cargo.toml --test backup_migration` 使用从上述 master 提取的结构 fixture 和冻结的最终开发版结构 fixture，覆盖：

- master 一次升级获得全部最终表、字段、索引和触发器。
- 原设置、任务、缓存、文案及完整 WAL 快照保留。
- 升级中途失败，设置、新表和版本标记整体回滚；修正失败条件后可重试。
- 新库与升级库结构一致，重复启动幂等。
- 最终开发库归并后保留资料、同步开关和未知发送证据。
- 未支持版本和旧开发 v1 在启动写入前拒绝；文案恢复不会嵌套结构事务。

测试只操作临时模拟数据库。真实本机库、线上服务、原生应用和安装器验收需分别记录，不能由离线迁移测试代替。
