# 映取 v1.9.0

本次更新新增文件命名规则、封面浏览和内置播放器，并优化下载任务的展示与操作体验。

### 文件命名规则

- **自定义下载路径与名称**：在下载设置中组合平台、作者、作品 ID、发布日期、描述、当前时间、序号和清晰度变量；使用 `/` 分隔文件夹，文件扩展名自动保留。
- **快捷插入与彩色预览**：点击变量快速插入，不同变量使用不同背景色，实时查看最终路径；优化连续插入和切换页面时的预览刷新。
- **普通文本照常保留**：无法识别的变量按普通文字处理，方便自由组合名称。

### 下载任务

- **封面浏览**：平台筛选栏右侧可切换列表与封面模式，重启应用后保留选择。封面按 3:4 展示，支持悬停反馈。
- **逐步加载**：默认展示前 30 条，向下滚动时提前加载，每次增加 10 条，并提供加载反馈。
- **更清晰的卡片状态**：完成徽章位于左上角，播放或图集入口位于右上角；下载中显示平滑变化的圆环百分比，错误信息显示在封面上方区域。
- **精简下载中卡片**：移除底部重复的下载中状态与取消按钮，取消操作仍可通过任务菜单使用。
- **复制本地地址**：已完成视频的右键菜单新增本地文件绝对路径复制；图集继续使用图集浏览入口。

### 内置播放器

- **直接播放本地视频**：点击播放后在应用内打开，支持进度拖动、音量和全屏；当前环境无法解码时自动尝试系统播放器，无需额外打包解码器。
- **记住播放位置**：各视频分别保存进度，关闭播放器或重启应用后继续播放；播放结束后下次从头开始。外部播放器的进度由其自行管理。
- **稳定的播放反馈**：修正播放操作导致其他播放按钮闪烁的问题，并为媒体弹窗统一添加打开和关闭反馈。

### 体验与维护

- 应用本地阿里巴巴普惠体，增大 Logo 文字，并调整任务 Tab 的间距与鼠标指针反馈。
- 解析期间禁用链接编辑；将“后台下载”设为主操作，“下载视频”更名为“立即下载”。
- 关闭输入框自动填充，减少浏览器保存信息浮层的干扰。
- 更新安装包缓存自动清理，只保留最新版本的完整安装包。

### 安装包

- Windows x64：`Yingqu_1.9.0_x64-setup.exe`
- macOS Intel：`Yingqu_1.9.0_x64.dmg`
- macOS Apple Silicon：`Yingqu_1.9.0_aarch64.dmg`

保留现有下载记录、本地文件、平台配置和已下载的语音模型。Windows 安装包未配置代码签名，macOS 使用 ad-hoc 签名。
