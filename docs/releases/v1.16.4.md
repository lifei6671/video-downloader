# 映取 v1.16.4

- Telegram 备份上传、远端删除和清理遇到限流时，按服务端指定的时间等待后自动继续，不再因反复限流耗尽失败重试次数。
- 限流期间显示“Telegram 请求受限，等待后自动继续”，无需手动点击重试；等待中的上传仍可取消，权限等实际错误继续明确提示。
- 升级后启用备份，会恢复旧版因限流停止的任务及清理依赖，保留原等待期限、上传记录和消息回执。

## 升级提示

- 已有备份和本机原件继续保留，无需删除或重新下载。
- 主动取消的上传和已停用的备份保持原状态。
