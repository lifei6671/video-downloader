# 映取 v1.10.4

发布日期为 2026-11-08。本次更新改进 Windows 安装与应用内更新流程，并精简桌面安装包。

## Windows 安装与更新

- 安装和卸载向导使用简体中文，安装包文件采用映取的蓝色图标。
- 升级到此版本后，下次在映取内打开 Windows 更新安装包，映取会在安装器成功启动后正常退出。若安装包校验失败或无法打开，映取会继续运行并显示错误。

## 安装包

- 桌面安装包移除开发测试用的 `m1-probe`。Windows 覆盖安装时会清理安装目录里旧版遗留的 `m1-probe.exe`。
- Windows x64 使用 `Yingqu-windows-x64-setup-1.10.4.exe`。
- macOS Intel 使用 `Yingqu-darwin-x64-1.10.4.dmg`。
- macOS Apple Silicon 使用 `Yingqu-darwin-aarch64-1.10.4.dmg`。
- 从 v1.10.2 升级时，请通过发行页面手动下载安装包。
