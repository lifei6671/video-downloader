# 映取 v1.14.0

- 抖音、小红书和微信视频号新增应用内登录。微信视频号使用腾讯元宝登录，TikTok 使用官方二维码。完成登录后，映取保存该平台的会话并关闭登录窗口。
- 平台账号设置可切换内置登录和手动 Cookie，切换会保留已保存的凭据。已移除系统浏览器 Cookie 自动读取。YouTube 可从设置打开浏览器登录，并手动填写 YouTube Cookie。
- 手动 Cookie 输入框直接显示明文。抖音支持粘贴以 `douyin.com;` 开头的复制内容，保存时会去掉域名前缀。
- 切换认证面板时保持标签和页面宽度稳定，内置登录面板按内容收起，保存时的提示也不会撑开表单。

## 安装包

- Windows x64 使用 `Yingqu-windows-x64-setup-1.14.0.exe`。
- macOS Intel 使用 `Yingqu-darwin-x64-1.14.0.dmg`。
- macOS Apple Silicon 使用 `Yingqu-darwin-aarch64-1.14.0.dmg`。
