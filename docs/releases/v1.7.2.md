# 映取 v1.7.2

本次更新修复视频规格判重、YouTube 音轨匹配与下载进度，并完善系统设置的配置回显和界面层级。

### 下载修复与改进

- **按视频规格识别重复下载**：同一作品的 1080P、4K 等不同规格可分别下载；相同规格已有成功记录且文件仍存在时才提示重复。文件已删除时可重新下载；规格未知的旧记录仍保守提示。
- **YouTube 自动音轨匹配更稳定**：根据有效的音轨偏好、作品语言和默认标记选择兼容音轨，避免格式列表顺序影响结果。下载时严格核对所选视频与音频；规格失效明确失败，不自动降低画质或替换音轨。
- **格式信息更准确**：归一化常见帧率和编码名称，保留不同编码的真实规格，区分已知大小、估算大小与未知大小。签名 URL 或 CDN 镜像变化不影响稳定规格身份。
- **进度与错误反馈更完整**：修复 ETA 传递，估算大小显示“约”，正确累计分离音视频的传输进度并显示合并状态。改进 HTTP、超时、断流及合并错误分类；仅对原生 HTTP 下载器判定的瞬态错误最多重试一次。

### 系统设置

- **YouTube HTTP 分块可配置**：在“系统设置 → 平台账号 → YouTube”选择继承上游默认、关闭分块或自定义 1–1024 MiB。默认仍继承上游配置；实际速度取决于网络与 CDN，本版本不承诺提速幅度。
- **代理地址支持回显与编辑**：重新进入平台设置可查看已保存的代理；代理密码继续由系统凭据存储保护。
- **设置导航保持在顶部**：平台账号标题和平台 Tab 固定，仅下方配置区域滚动。
- **统一文字层级**：辅助说明采用小一号灰色常规字体，四个平台的配置卡片标题统一加粗。

### 兼容性

- 保留现有任务记录、本地文件、下载队列与不覆盖提交机制。引擎更新使旧解析缓存重新提取，已有成功记录和文件保持。
- 内置引擎 0.7.5，yt-dlp 仍固定为 2026.08.19，DTK 仍为 5.1.3；YouTube 分离音视频继续使用本机 FFmpeg 无损合并。
