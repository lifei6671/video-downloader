# 映取 v1.16.6

- 检查更新改为读取随版本发布的静态清单 `update.json`，减少对 GitHub REST API 及其匿名请求额度的依赖。
- 安装包下载前读取所选版本的清单，继续核对系统架构、文件大小和 SHA-256；取消下载和安装包校验流程保持可用。
- 分别提示更新服务拒绝访问、请求过于频繁、更新信息暂不可用及网络错误，避免将访问失败统一显示为请求频繁。
- 保留普通 GitHub Release 和原有安装包命名，旧版仍可通过 GitHub API 查询并升级，新版使用静态清单查询。

## 升级提示

- 已有下载、备份记录和设置继续保留。
- 旧版若因 GitHub API 限流无法检查更新，可等待额度恢复，或从本发行页面下载安装包升级。升级后检查更新使用静态清单。

## 安装包

- Windows x64 使用 `Yingqu-windows-x64-setup-1.16.6.exe`。
- macOS Intel 使用 `Yingqu-darwin-x64-1.16.6.dmg`。
- macOS Apple Silicon 使用 `Yingqu-darwin-aarch64-1.16.6.dmg`。
- `update.json` 为客户端自动读取的更新信息，无需手动安装。
