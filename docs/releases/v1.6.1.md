# 映取 v1.6.1

本次更新补齐“下载作品”链接输入框的右键编辑操作。

### 修复与改进

- **链接输入框右键菜单**：支持全选、剪切、复制、粘贴和清空。剪切、复制作用于选中文字；粘贴插入光标处或替换选区；清空移除全部文字。
- **保留编辑位置**：关闭菜单后恢复输入焦点，剪切或粘贴后光标停在编辑位置；Windows 多行剪贴板内容按输入框规则处理换行，避免光标偏移。
- **保留原文与键盘操作**：剪贴板读写失败时提示原因并保留原文，迟到的粘贴结果不会覆盖其他页面的输入。支持 Shift+F10 打开菜单及键盘选择，原有 Enter 解析、Shift+Enter 换行保持可用。

### 安装包

- Windows x64：`Yingqu_1.6.1_x64-setup.exe`
- macOS Intel：`Yingqu_1.6.1_x64.dmg`
- macOS Apple Silicon：`Yingqu_1.6.1_aarch64.dmg`
