# 映取 v1.16.2

- Telegram 图集备份合并为一条消息，直接展示图片和可播放的 Live Photo 配套视频。无损原图、原视频与备份数据保留在折叠附件中，不再打包成 TAR 或逐项发送多条消息。
- 图片展示预览与原件分开保存，恢复时校验原始文件的大小和摘要。Telegram 不接受图片展示格式时，改为同一条消息内的文件附件；历史 TAR 备份仍可恢复。
- 修复图集本地下载完成后提前显示“已完成”的问题。图集与普通视频共用备份状态，启用备份时，只有当前空间确认备份成功才显示完成；取消、失败和重试状态也保持一致。

## 升级提示

- 使用新格式备份的图集，需要 v1.16.2 或更新版本恢复。旧 TAR 备份无需迁移，已有备份消息不会自动重排。
- 直接展示的图片可能经过 Telegram 处理，完整恢复使用保留的无损原件。

## 安装包

- Windows x64 使用 `Yingqu-windows-x64-setup-1.16.2.exe`。
- macOS Intel 使用 `Yingqu-darwin-x64-1.16.2.dmg`。
- macOS Apple Silicon 使用 `Yingqu-darwin-aarch64-1.16.2.dmg`。
