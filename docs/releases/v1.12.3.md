# 映取 v1.12.3

- 修复启动时主窗口提前显示造成的白屏。映取会先显示「正在启动…」，在后台初始化数据库，读完设置和下载任务后进入首页。
- 启动页新增影片卡片动画。小卡片滑入映取图标，图标轻弹并荡开一圈波纹。启用系统的「减少动态效果」时显示静态图标。

## 安装包

- Windows x64 使用 `Yingqu-windows-x64-setup-1.12.3.exe`。
- macOS Intel 使用 `Yingqu-darwin-x64-1.12.3.dmg`。
- macOS Apple Silicon 使用 `Yingqu-darwin-aarch64-1.12.3.dmg`。
