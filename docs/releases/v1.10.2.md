# 映取 v1.10.2

发布日期为 2026-11-07。本次更新新增小红书下载，并改进图集浏览和重新下载。

## 小红书

- 支持网页分享链接和 App 短链，可直接粘贴分享文案。支持下载无水印视频和高清图文图片，解析后显示视频时长与可用的作者头像。
- 默认匿名访问。遇到访问限制时，可在「系统设置 → 平台账号 → 小红书」沿用浏览器 Cookie 或手动填写。
- 实况照片会保存静态图和同编号的 MP4，下载完成后可在图集中播放。此前只保存了静态图的作品可重新下载，补齐实况片段。

## 图集与下载

- 图集弹窗按整组图片的最大宽度和高度确定尺寸。切图时弹窗保持稳定，底部圆点覆盖在图片上，点击圆点和滚轮切换均支持过渡动画。
- 确认重新下载已完成的同规格作品后，沿用原任务和原保存位置。新文件校验通过后才替换旧文件，失败或取消会保留原下载。规格未知的历史视频可另存一份。
- 重新下载成功后会清空提交的链接，下载期间输入的新内容会保留。
- 「下载设置 → 文件命名规则」新增「作者 ID」变量 `{user_id}`，可用于文件名或按作者分目录。

## 安装

- Windows x64 使用 `Yingqu_1.10.2_x64-setup.exe`。
- macOS Intel 使用 `Yingqu_1.10.2_x64.dmg`。
- macOS Apple Silicon 使用 `Yingqu_1.10.2_aarch64.dmg`。
- macOS 最低版本为 13.3。
