# 映取 v1.9.1

本次更新修复封面模式下的卡片布局与右键菜单，改善下载过程和封面浏览体验。

### 下载任务

- **卡片高度保持一致**：下载和合并期间隐藏清晰度、图片数量、文件大小等规格信息，由下载进度占用相同空间，减少与已完成卡片之间的高度差异；下载完成后恢复规格信息。
- **统一卡片右键菜单**：在封面或卡片其他区域右键，均可使用保存封面、复制封面及原有任务操作；下载期间仍可通过菜单取消下载。
- **修复封面悬停效果**：封面仅在鼠标悬停时放大，关闭详情弹窗后恢复正常，避免键盘焦点导致封面持续放大。

### 安装包

- Windows x64：`Yingqu_1.9.1_x64-setup.exe`
- macOS Intel：`Yingqu_1.9.1_x64.dmg`
- macOS Apple Silicon：`Yingqu_1.9.1_aarch64.dmg`

保留现有下载记录、本地文件、平台配置和已下载的语音模型。Windows 安装包未配置代码签名，macOS 使用 ad-hoc 签名。
