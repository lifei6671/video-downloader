本次更新新增 Telegram 视频下载实验模式，并完善后台下载、历史清理和本地播放体验。

### Telegram 视频下载

- **原始视频下载**：新增基于本机 tdl 的 HTTP 实验模式，支持单条 Telegram 消息视频，复用现有下载队列、进度、取消与完成记录。下载中可继续解析同一服务支持的其他消息。
- **应用内登录**：在“系统设置 → 平台账号 → Telegram”扫码登录，并按提示输入两步验证密码。每次登录创建独立会话，不覆盖已有会话；密码仅用于本次登录，不保存。
- **依赖检测与配置**：在“运行依赖”自动检测 tdl，也可通过文件选择器指定路径，或手动输入后按 Enter 保存并检测。检测结果在页面切换后保留。
- **下载后生成封面**：使用 FFmpeg 从视频前 30 秒采样，跳过近乎全黑的画面。封面用于应用展示和重启恢复，下载目录只保留原视频；缺少 FFmpeg 或抽帧失败不影响视频下载成功。

### 下载任务与交互

- **后台下载**：将当前作品加入下载任务后清空输入与预览，可继续粘贴和解析下一个链接。
- **清空历史记录**：确认后移除已完成、失败和已取消的下载记录，保留本地文件、活动任务和当前预览。
- **本地播放**：已完成的视频可直接使用系统默认播放器打开，播放、打开文件夹和移除记录采用统一的图标按钮与说明提示。
- **进度与反馈**：下载中展示预计剩余时间，统一成功、错误等 Toast 提示和关闭按钮样式。
- **更新说明**：应用内支持 Markdown 格式，标题、列表和链接更清晰，长内容可滚动阅读。

### Telegram 使用说明

实验模式默认关闭，需自行安装 tdl，并在“平台账号 → Telegram”阅读提示后启用。暂不支持 Telegram 相册、话题或批量消息；当前服务尚未确认的新用户名频道需改用数字频道链接。

tdl HTTP 服务会监听所有网络接口，缺少访问令牌和消息白名单；请在可信网络使用，并通过系统防火墙限制外部访问。映取不内置或自动安装 tdl。详见 [Telegram tdl 使用说明](https://github.com/lifei6671/video-downloader/blob/v1.4.0/docs/tdl-integration.md)。
