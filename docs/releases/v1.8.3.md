# 映取 v1.8.3

本次更新修正进度展示，稳定 YouTube 下载测速，并为视频文案接入真实的片段识别进度。

### 下载进度

- **修正初始填充**：尚未取得实际进度时，不再预先填充一段进度条；收到百分比后按真实数值展示。
- **稳定 YouTube 测速**：按实际累计下载字节约每秒更新速度，避免分块下载和音视频流切换导致数值快速跳动或频繁变成未知。
- **区分下载与合并**：音视频下载完进入合并阶段后，只显示合并状态和已下载大小，不再显示下载进度条、速度或预计下载剩余时间。

### 视频文案

- **真实识别进度**：CPU 和 CUDA 识别均按已完成片段展示“已识别 X / Y 段”和百分比；模型加载时单独显示加载状态，不按用时估算进度。
- **支持全选复制**：文案区域改为只读文本框，支持鼠标选择和系统全选、复制快捷键；Windows 使用 Ctrl+A / Ctrl+C，macOS 使用 Cmd+A / Cmd+C。
- **保留正文与选区**：识别进度更新不再反复读取或清空正文；关闭后重新打开弹窗可继续查看当前进度。
- **复制成功反馈**：“复制全文”成功后显示“已复制”，保留原有导出 TXT 和重新提取操作。

### 安装包

- Windows x64：`Yingqu_1.8.3_x64-setup.exe`
- macOS Intel：`Yingqu_1.8.3_x64.dmg`
- macOS Apple Silicon：`Yingqu_1.8.3_aarch64.dmg`

保留现有下载记录、本地文件、平台配置和已下载的语音模型。Windows 安装包未配置代码签名，macOS 使用 ad-hoc 签名。
