# 映取 v1.15.0

- S3、Cloudflare R2 和 Telegram 新增数据库备份。在「系统设置 → 远端备份」开启后，可自设或自动生成恢复密码。数据库在本机加密后上传，恢复时需要原密码。
- 自动备份可设为每 1、3、6 或 24 小时，也可手动点击「立即备份」。设置页显示上传进度、当前速度和上次成功备份的平均速度，进行中的备份可以取消。
- 换机时，用数据库备份恢复任务列表和云端视频引用，视频仍按需下载。S3/R2 可按时间选择快照，Telegram 可粘贴备份消息链接直接验证所选快照，无需扫描频道历史。
- 新的视频备份按单个视频保存相关数据。换机前请在旧设备上先完成一次数据库备份，并保存恢复密码。使用 Telegram 时请同时保存数据库备份链接。

## 安装包

- Windows x64 使用 `Yingqu-windows-x64-setup-1.15.0.exe`。
- macOS Intel 使用 `Yingqu-darwin-x64-1.15.0.dmg`。
- macOS Apple Silicon 使用 `Yingqu-darwin-aarch64-1.15.0.dmg`。
