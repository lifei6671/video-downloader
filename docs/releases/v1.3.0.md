本次更新围绕版本更新、运行环境和设置体验，让下载与日常配置更顺手。

### 新增功能

- **关于软件**：新增版本信息、项目入口与开源致谢，点击开源组件可前往对应的 GitHub 项目。
- **检查更新**：获取最新正式版本，在弹窗中查看版本号、发布时间和更新说明，并可前往发行页面下载。
- **下载更新**：自动匹配 Windows、macOS Intel 或 Apple Silicon 安装包，显示下载进度、支持取消；下载校验完成后可直接打开安装包继续安装。
- **运行依赖**：在“系统设置 → 运行依赖”检测 FFmpeg / FFprobe 和 JavaScript 运行时，按需下载缺失工具。优先使用已有可用工具，下载的依赖保存在应用专属目录。

### 设置与任务体验

- **统一下载任务**：合并“下载任务”和“已完成”，在一个列表中查看下载进度、完成记录和本地文件位置，并搜索标题或作者。
- **重整系统设置**：采用左侧分类、右侧操作区的布局，分为下载设置、平台账号和运行依赖；分类菜单使用紧凑单行和背景高亮。
- **按平台统一配置**：抖音、TikTok、YouTube 使用顶部标签切换，每个平台的 Cookie、网络代理与 User-Agent 集中在同一配置区，切换时保留未保存的输入。
- **减少重复检测**：每次启动自动检测一次运行依赖，切换页面时复用结果；需要时可手动重新检测。

### 交互优化

- 作品链接输入区新增“粘贴链接”，通过系统剪贴板填入完整分享文案；点击粘贴不会自动开始解析。
- 链接输入框固定为三行，长文本在框内滚动；粘贴与解析按钮上下排列。
- 检查更新时仅在按钮上显示加载状态，没有新版本时通过顶部提示告知；统一将 Toast 提示放在顶部。
- 调整设置菜单的选中、悬停和键盘焦点样式，避免背景高亮重叠。

### 安装包

- Windows x64：`Yingqu_1.3.0_x64-setup.exe`
- macOS Intel：`Yingqu_1.3.0_x64.dmg`
- macOS Apple Silicon：`Yingqu_1.3.0_aarch64.dmg`
