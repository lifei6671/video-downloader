# 映取 v1.10.3

发布日期为 2026-11-08。本次更新加入流式播放，并统一安装包命名。

## 流式播放

- 右键点击下载列表中的视频或图集，选择「流式播放」。上下滚动按当前列表顺序切换，画面和右侧详情一起滑动，弹窗尺寸保持稳定。
- 视频自动循环，应用会预载相邻的本地视频，播放就绪后恢复滚轮切换。图集自动循环翻页，带淡化过渡，也支持滚轮逐张查看。向下进入图集从第一张开始，向上进入从最后一张开始。
- 右上角可以在应用窗口内最大化和还原，封面操作与关闭按钮独立排列。

## 安装

- Windows x64 使用 `Yingqu-windows-x64-setup-1.10.3.exe`。
- macOS Intel 使用 `Yingqu-darwin-x64-1.10.3.dmg`。
- macOS Apple Silicon 使用 `Yingqu-darwin-aarch64-1.10.3.dmg`。
- 从 v1.10.2 升级时，在应用内点击「前往发行页面」，手动下载本次安装包。
