# 映取 v1.12.0

发布日期为 2026-11-11。本次更新新增作品发布时间和同步任务筛选，并优化本地封面存储。

## 作品预览与作者资料

- 单链接解析后，作品预览会显示平台提供的发布时间。有具体时间时按本机时区显示到秒，只有日期时显示原日期。缺少时间的作品和旧解析缓存会省略这一行。
- 作者主页的粉丝数不足 1 万时直接显示整数，达到对应量级后以「万」「千万」「亿」显示，保留一位小数。

## 同步任务

- 「下载任务」顶部新增「同步中」状态筛选，和「已完成」「失败」并列。支持按平台和关键词筛选，也可切换列表和卡片。
- 任务按上传队列显示「待同步」「同步中」「同步失败」或「待确认」。已知的同步错误会显示在任务内，同步完成后任务会自动移出该筛选。

## 封面存储

- 解析缓存、下载记录和备份共用相同封面的原始图片数据，减少 SQLite 中的重复存储。
- 升级时先保存本地数据库快照，再迁移已有封面。备份重试仍能读取该次上传所使用的封面版本。

## 安装包

- Windows x64 使用 `Yingqu-windows-x64-setup-1.12.0.exe`。
- macOS Intel 使用 `Yingqu-darwin-x64-1.12.0.dmg`。
- macOS Apple Silicon 使用 `Yingqu-darwin-aarch64-1.12.0.dmg`。
