# 映取 v1.8.4

本次更新修正取消预览后的页面重置，并完善视频文案弹窗的边框、滚动和复制反馈。

### 下载作品

- **取消后重置首页**：尚未提交下载的解析或已解析预览，在确认取消成功后清空原链接和预览，回到“粘贴链接开始解析”，并聚焦链接输入框。
- **保留新输入**：等待取消期间输入的新链接会保留；取消失败时保留预览与错误提示。任务列表和已提交下载的取消、重试行为保持不变。

### 视频文案

- **完整显示焦点边框**：修正文本框上侧、左侧蓝色焦点线被裁切的问题，聚焦时四边保持完整可见。
- **正文内部滚动**：长文案在文本框内部滚动，标题、提取时间和底部操作保持固定；继续支持全选、复制和完整导出 TXT。
- **精简复制反馈**：移除顶部“文案已复制”提示，保留“复制全文”按钮上的“已复制”反馈。

### 安装包

- Windows x64：`Yingqu_1.8.4_x64-setup.exe`
- macOS Intel：`Yingqu_1.8.4_x64.dmg`
- macOS Apple Silicon：`Yingqu_1.8.4_aarch64.dmg`

保留现有下载记录、本地文件、平台配置和已下载的语音模型。Windows 安装包未配置代码签名，macOS 使用 ad-hoc 签名。
