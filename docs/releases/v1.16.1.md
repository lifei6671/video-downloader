# 映取 v1.16.1

- 图集纳入 S3、Cloudflare R2 和 Telegram 媒体备份。已保存的原图与 Live Photo 配套视频按原始字节完整上传，恢复时校验文件完整性、顺序和图片与视频的对应关系。启用同步后，完整的已有图集也会补录到所选空间。
- 新增 B 站视频解析与下载，支持手动配置 Cookie，或通过内置窗口登录并自动保存会话。修复部分 B 站视频无法保存任务记录的问题。
- 补全 B 站作者头像与简介，在作品预览、任务列表和作者主页显示。已有记录会在下次解析时补充资料。
- 内置登录使用系统浏览器组件的真实设备信息，并与 Cookie 一起保存，供后续解析和下载使用。各平台保留独立登录环境，手动 Cookie 的来源浏览器 UA 独立保存；Telegram 使用实际系统信息。

## 升级提示

- 已有内置登录请重新登录一次，绑定当前浏览器的设备信息。平台仍可能要求扫码、验证码或其他验证。
- 图集媒体需要成功上传后才能在其他设备完整恢复；数据库快照本身不包含本地原图和 Live Photo 视频。参与图集恢复的设备均需升级到支持图集备份的版本。

## 安装包

- Windows x64 使用 `Yingqu-windows-x64-setup-1.16.1.exe`。
- macOS Intel 使用 `Yingqu-darwin-x64-1.16.1.dmg`。
- macOS Apple Silicon 使用 `Yingqu-darwin-aarch64-1.16.1.dmg`。
