本次更新改进 Telegram 下载中的链接解析：已确认过的频道可复用缓存中的数字 ID，新频道也能先加入队列，服务空闲后自动解析并下载。

### 新功能与改进

- **复用频道映射**：从已有解析缓存读取频道用户名与数字 ID 的对应关系，同频道的其他消息可在下载期间继续解析，支持 `t.me`、`telegram.me` 和用户名大小写。
- **新频道先排队**：当前 Telegram 服务被占用、尚未确认新频道时，点击提示下方的“加入待下载队列”，无需手动查找数字 ID。前面的 Telegram 操作结束且有下载名额后，自动解析并下载。
- **保持下载连续**：沿用现有 tdl 服务和认证，不为此额外扫码，也不重启正在下载的服务；等待中的新频道不会占用下载名额，其他平台可继续下载。
- **队列状态更清楚**：未解析任务显示原链接和“等待解析”，支持独立取消；解析失败保留原因和链接，重试继续使用原任务记录。重启后未完成任务标为中断，可手动重试。

Telegram 仍为需自行安装 tdl 的 HTTP 实验模式。本次不修改上游 tdl，不新增登录会话；已有的服务暴露风险和启用确认保持不变。
