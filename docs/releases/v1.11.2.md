# 映取 v1.11.2

发布日期为 2026-11-11。本次更新补齐作者主页，修复升级后已有头像显示为占位的问题。

## 作者主页与头像

- 点击作品预览或下载任务中的作者昵称，打开作者主页。主页展示已保存的头像、简介和公开资料，下方的本地视频与图集可切换列表或卡片展示。
- 同一作者的作品共用一份作者资料和头像。Telegram 按频道归并，抖音主页省略较长的作者 ID。
- 直接读取已保存在作者表中的头像，升级时迁移旧缓存中的可用头像。已有图片可以恢复显示，无需重新下载作品。

## 安装包

- Windows x64 使用 `Yingqu-windows-x64-setup-1.11.2.exe`。
- macOS Intel 使用 `Yingqu-darwin-x64-1.11.2.dmg`。
- macOS Apple Silicon 使用 `Yingqu-darwin-aarch64-1.11.2.dmg`。
