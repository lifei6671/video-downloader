# 映取 v1.7.1

本次更新补齐封面的保存、复制和大图预览，并改进下载任务列表的操作与清理体验。

### 新增功能

- **保存与复制封面**：在下载任务封面上右键，可保存封面或将图片直接复制到剪贴板。单击封面可打开大图预览，预览中的图片同样支持右键另存为和复制。
- **自适应封面预览**：浮层根据封面的实际宽高调整尺寸，横图、竖图均保持比例，在窗口内完整展示；长标题不会将竖图浮层撑宽。

### 修复与改进

- **抖音原始封面优先**：优先使用抖音详情中的 `cover_original_scale`；没有可用地址时沿用原有封面选择逻辑。后续解析不再命中旧引擎版本的缓存，已有历史任务封面不会被自动替换。
- **任务操作直接可见**：复制原链接、从列表移除和删除本地视频直接显示为图标按钮，不再收进“更多”菜单；删除本地文件的垃圾桶默认显示为红色，并保留悬停提示和键盘操作。
- **删除操作无需二次确认**：单条从列表移除只删记录、保留本地文件；删除本地视频或图集会同步移除对应下载任务和数据库下载记录。图集只删除任务所属图片，保留用户放入目录的额外文件。
- **列表交互更顺畅**：平台 Tab、标题和搜索框保持在顶部，仅下方任务列表滚动。删除后不再自动聚焦搜索框；成功删除或清理时，条目向上淡出，下方条目平滑上移。系统开启“减少动态效果”时直接移除。
- **按当前平台清理历史**：顶部清理按钮只处理当前 Tab 内已完成、失败或已取消的下载记录，“全部”Tab 才覆盖所有平台。搜索条件不改变清理范围，进行中和排队任务保留；批量清理仍保留确认，且不删除本地文件。
