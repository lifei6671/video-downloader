# 映取 v1.12.2

- 作者主页的列表和卡片按作品发布时间从新到旧排列，缺少发布时间的作品排在末尾。从主页进入流式播放时沿用这一顺序。
- 抖音作者主页的全量和增量下载均优先处理发布时间最早的作品，缺少发布时间的作品排在批次末尾。
- 普通播放和流式播放在右侧标题下显示作品发布时间。具体时间按本机时区显示到秒，只有日期时只显示日期，缺少数据时省略。新备份会保留已知的发布时间。

## 安装包

- Windows x64 使用 `Yingqu-windows-x64-setup-1.12.2.exe`。
- macOS Intel 使用 `Yingqu-darwin-x64-1.12.2.dmg`。
- macOS Apple Silicon 使用 `Yingqu-darwin-aarch64-1.12.2.dmg`。
