本次更新修复抖音下载规格中混入无声视频的问题，让可选规格与实际下载内容保持一致。

### 修复与改进

- **过滤无声规格**：按每个实际播放地址的音轨信息区分规格，只展示已确认同时包含视频轨和音频轨的一体规格；分离视频、纯音频及信息不明的规格不再进入下载列表。
- **解析与下载保持一致**：下载时重新获取并核对所选规格。旧的无声规格失效时明确提示不可用，不自动换成其他规格。
- **刷新旧解析结果**：更新后旧版解析缓存失效，重新解析可获得修正后的规格列表；已有下载记录和本地文件保留。
- **规格说明更清楚**：抖音预览区增加一体规格说明，继续展示真实分辨率、编码、码率和大小。

已在 Windows 桌面端验证实际规格列表与下载：测试作品显示 11 个一体规格，1080p H.265 文件包含 AAC 双声道音轨。

- macOS Intel：`Yingqu_1.5.2_x64.dmg`
