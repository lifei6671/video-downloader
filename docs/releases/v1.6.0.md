# 映取 v1.6.0

本次更新增加下载任务的平台筛选，并改进平台配置、视频封面存储和版本号显示。

### 新增功能

- **按平台查看任务**：下载任务顶部新增“全部、抖音、TikTok、YouTube、Telegram”标签，默认展示全部，可与标题或作者搜索同时使用。筛选不改变下载队列和任务状态。

### 修复与改进

- **Cookie 保存更顺畅**：抖音、TikTok、YouTube 自动清理 Cookie 首尾的空白和空行；保存成功后回显清理后的内容。中间内容保持原样，内部换行仍会提示格式错误。
- **保留浏览器 Cookie 模式**：保存后、切换平台或重新打开设置时，正确恢复默认浏览器 Cookie 选项。读取失败时，保存其他设置不会覆盖已有 Cookie。
- **代理地址可见**：自定义代理地址改为明文输入，自动去除首尾空白，并补充完整地址与系统 TUN 的使用说明。
- **视频封面统一存入数据库**：抖音、TikTok、YouTube 新下载视频的封面与 Telegram 一样只保存在 SQLite 缓存，不再在视频旁生成封面图片。重启后仍可显示，单独删除视频会保留封面；移除最后一个引用记录时清理封面缓存。旧版封面文件和图集原图保持原样。
- **修复长版本号溢出**：左上角应用名称保持单行，长版本号自动省略，悬停可查看完整版本。
- **明确平台验证提示**：遇到平台验证或访问限制时，提示浏览器验证与 TUN/代理出口检查方向；保留既有网络边界，不保证绕过平台验证。

默认浏览器 Cookie 读取仍可能受浏览器占用或系统加密限制；选项已保存不代表 Cookie 已成功读取或登录身份有效。
