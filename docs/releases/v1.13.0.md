# 映取 v1.13.0

- 新增微信视频号单条视频的本地解析与下载（实验功能）。粘贴 `weixin.qq.com/sph/` 分享链接，预览标题、作者和封面。可用的清晰度、时长和文件大小会在预览中显示，有多种编码时可选择 H.264 或 H.265。
- 微信视频号需要登录时，可在「系统设置 → 平台账号 → 微信视频号」填写腾讯元宝网页 Cookie。下载校验依赖 FFmpeg 和 FFprobe，可在「系统设置 → 运行依赖」安装。Windows 手动 Cookie 下载已实测，macOS 实际下载及默认浏览器登录态仍待验证。
- 修复只解析了视频就出现在作者主页作品记录的问题。发起下载后，作品才会计入作者主页的作品数和播放列表。
- Windows 和 macOS 安装包提供 GitHub 构建来源证明。

## 安装包

- Windows x64 使用 `Yingqu-windows-x64-setup-1.13.0.exe`。
- macOS Intel 使用 `Yingqu-darwin-x64-1.13.0.dmg`。
- macOS Apple Silicon 使用 `Yingqu-darwin-aarch64-1.13.0.dmg`。
