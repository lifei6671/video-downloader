# 映取 v1.8.2

本次更新优化下载任务的信息展示和封面体验，并完善列表操作细节。

### 下载任务

- **封面与详情合并**：点击任务封面，在同一窗口左侧查看完整封面、右侧查看任务信息；标题不再单独弹出详情。封面缺失时仍可查看信息，长内容独立滚动。
- **统一封面背景**：详情窗口使用与下载作品页一致的柔和模糊背景，前景保持原始比例；保存和复制封面仍使用原图。
- **双击播放**：双击已完成且文件可用的视频任务行，调用系统默认播放器；封面、按钮和图集保留各自操作。
- **昵称与下载时间**：作者优先展示昵称，无昵称时使用可用的账号标识；下载完成时间显示在文件大小后。
- **一键清空搜索**：搜索框有内容时显示清空图标，支持鼠标与键盘操作；清空后保留当前平台和状态筛选。
- **列表更易区分**：相邻任务的选中和悬停背景之间增加留白，修正侧栏任务数量的垂直对齐。

### 抖音封面

- 优先选择与原封面画面一致、实际尺寸更大的静态高清封面；候选不可用或无法确认画面一致时，保留原有封面回退逻辑。
- 同时适用于 yt-dlp 与 DTK 解析路径，新获取的封面沿用数据库缓存与现有保存方式；不自动替换历史封面。

### 其他调整

- 修正系统设置左侧子菜单分隔线高度，使其跟随右侧区域延伸。
- 关于软件的品牌区补充 Telegram 徽章，并标明实验模式。

### 安装包

- Windows x64：`Yingqu_1.8.2_x64-setup.exe`
- macOS Intel：`Yingqu_1.8.2_x64.dmg`
- macOS Apple Silicon：`Yingqu_1.8.2_aarch64.dmg`

保留现有下载记录、本地文件和平台配置。Windows 安装包未配置代码签名，macOS 使用 ad-hoc 签名。
