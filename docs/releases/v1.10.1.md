# 映取 v1.10.1

发布日期为 2026-11-07。本次更新改进下载任务的播放与图集浏览，并补充解析进度和下载设置。

## 播放与图集

- 修复抖音实况图下载后只剩静态图的问题。每张实况图会同时保存原图和原始 MP4，在图集中可以播放。旧记录如需补齐实况片段，可重新解析并下载。
- 点击视频封面或播放按钮，都会打开同一个弹窗并自动播放。左侧展示视频或图集，右侧可独立滚动查看任务详情。视频的「使用系统播放器」入口位于右侧底部。
- 预览按当前媒体的实际比例布局。窗口空间足够时显示原始尺寸，空间不足时等比缩小，减少横屏和竖屏画面周围的空白。
- 多项图集可以点击底部圆点或使用鼠标滚轮切换。滚轮切换普通图片时，下一张加载完成后淡出上一张。
- 下载任务列表在作者昵称前显示头像。解析 Telegram 作品时获取并缓存频道头像，可在任务列表和详情中查看。

## 下载与设置

- 「下载作品」在解析过程中显示读取作品信息、整理可用规格、准备解析结果三个阶段。失败时保留当前阶段和原因，Telegram 重连时显示连接状态。
- 「同时下载数量」改为滑块，可设为 1–10 个任务，新设置默认 5。已有并发设置保留，滑块保存时维持布局和显示状态。
- 平台账号新增「解析与下载不走代理」。使用系统 TUN 或透明代理时可手动开启，绕过应用配置的代理并保留原代理地址，关闭后恢复。
- 缩小 Toast 的占用空间，并对齐下载任务页与其他页面的顶部标题。

## 升级与安装

- 支持 Windows x64、macOS Intel 和 macOS Apple Silicon。macOS 最低版本为 13.3。
- 若将并发数量设为 6–10 后需要退回 v1.10.0，请先在新版中调回 1–5。
