# 映取 v1.16.3

- 修复包含 Live Photo 的图集备份到 Telegram 时长期卡住的问题。配套视频保留可播放的原始文档，避免重复作为文件附件引用导致 Telegram 拒绝保存。
- 图集重试时先核对原有消息，已上传的成员直接接续，确认缺失的成员继续追加到同一条消息。升级后，因发送结果未确认而停止重试的图集会重新排队。
- 保留首次发送错误及脱敏后的 Telegram 错误信息，后续重试或成功不再覆盖首次原因，方便定位问题。

## 升级提示

- 已有图集备份和本机原件继续保留，无需删除后重新下载。
- 重启后，已提交的中断下载和未完成备份会自动继续；下载从头重新开始，不提供跨启动断点续传。主动取消的任务和已停用的备份保持原状态。
- 历史上已经被覆盖的首次错误无法还原；升级后的首次已知错误会持续保留。

## 安装包

- Windows x64 使用 `Yingqu-windows-x64-setup-1.16.3.exe`。
- macOS Intel 使用 `Yingqu-darwin-x64-1.16.3.dmg`。
- macOS Apple Silicon 使用 `Yingqu-darwin-aarch64-1.16.3.dmg`。
