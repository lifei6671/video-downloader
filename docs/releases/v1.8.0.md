# 映取 v1.8.0

本次更新新增本地视频语音转录，支持提取文案、复制全文和导出 TXT，并提供 Windows CUDA 可选加速。

### 视频文案

- **从已下载视频提取文案**：在下载任务中点击“提取文案”，使用 Fun-ASR-Nano 在本机识别视频语音；支持复制全文、导出 TXT 和重新提取。
- **模型按需下载**：首次使用或在“系统设置 → 运行依赖”中下载，安装包不包含模型权重。CPU 模型约 1.2 GiB；下载、校验及推理验证成功后才启用。
- **保留已有结果**：文案保存到本机，重新提取失败或取消时保留旧文案；历史 SenseVoiceSmall 文案仍可查看、复制和导出。
- **修复长文案显示**：正文在弹窗内滚动，底部操作保持可见；提取过程中不再出现闪烁的滚动条。

### Windows CUDA 加速

- **同一模型依赖选择 CPU 或 CUDA**：选择安装 CUDA 版后检查 NVIDIA 显卡和驱动，兼容后再下载；真实推理验证成功才切换，失败或取消保留原版本。
- **独立语音分段**：采用 audio.cpp CUDA 配合独立 FSMN-VAD，再按片段顺序识别。缺少片段输出时明确报错，避免将不完整结果保存为成功文案。
- **无需安装开发环境**：程序内置 Python 运行环境；CUDA 版按需下载所需程序和 CUDA DLL，无需另装 CUDA Toolkit、PyTorch 或系统 Python。设备仍需兼容的 NVIDIA 显卡及驱动。
- **版本可切换**：CPU 与 CUDA 使用不同模型文件，分别安装并保留；已下载的 VAD 校验后复用，两版完整安装后切换无需重复下载。CUDA 首次下载合计约 2 GiB。

### 系统设置与兼容性

- **依赖分别管理**：运行依赖按项展示检测状态与下载操作，重新检测和状态说明固定在顶部。
- **滚动条与布局调整**：使用窄灰色滚动条，悬停变黑，保留上下箭头并调整边缘间距；下载按钮与所属依赖保持在同一区域。
- Windows CUDA 当前面向受支持的 NVIDIA 显卡；不兼容或驱动缺失时提示选择 CPU，不自动安装驱动。macOS Intel / Apple Silicon 保持 CPU 转录。
- 保留原有任务记录、下载文件和平台配置。内置引擎更新为 0.12.0，yt-dlp 仍为 2026.08.19，DTK 仍为 5.1.3。
