# 映取 v1.11.0

发布日期为 2026-11-11。本次更新支持批量下载抖音主页的视频和图集，并改进图集播放。

## 抖音主页下载

- 在「下载作品」粘贴抖音主页链接或分享文案，点击「解析链接」即可开始扫描。单作品链接也使用同一个输入框。
- 扫描结束后显示已下载和待下载数量。增量下载只处理本次扫到且尚未保存到本地的作品，全量下载会在新文件校验通过后替换已下载的视频和图集。失败任务可在「下载任务」中重试。
- 扫描中可随时停止，在同一次应用会话内继续或从第一页重置。重新解析主页从第一页开始。取消、确认入队或退出应用会清除扫描结果。
- 视频和图集进入同一下载队列，任务列表显示作品封面和作者头像。

## 图集与流式播放

- 普通图集支持自动翻页并循环回到首张，也可以用滚轮或圆点手动翻页。
- 流式播放中可以用滚轮在作品之间切换，普通图集中的滚轮只翻当前图集。

## 安装包

- Windows x64 使用 `Yingqu-windows-x64-setup-1.11.0.exe`。
- macOS Intel 使用 `Yingqu-darwin-x64-1.11.0.dmg`。
- macOS Apple Silicon 使用 `Yingqu-darwin-aarch64-1.11.0.dmg`。
