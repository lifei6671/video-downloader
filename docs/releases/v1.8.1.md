# 映取 v1.8.1

本次更新重构浅色桌面界面，提升下载任务浏览与操作效率，并优化封面加载体验。

### 下载任务

- **更清爽的连续列表**：统一侧栏、工具栏和任务行样式，采用轻量浅色布局；悬停和选中使用整行圆角背景。
- **状态与平台组合筛选**：按全部、下载中、等待中、已完成、失败查看任务，可叠加平台筛选与标题、作者搜索；计数随真实任务更新。
- **更紧凑的操作区**：播放改为图标按钮；在任务行右键可打开文件夹、提取或查看文案、复制原链接、移除记录和删除本地文件，原有操作条件及删除语义保持不变。
- **更轻快的菜单**：调整菜单间距、图标与阴影，缩短出现和关闭动画，保留键盘操作及焦点恢复。
- **信息更清晰**：标题与作者、平台、清晰度、大小分层显示；完整信息可在任务详情中查看，失败原因与文件缺失提示持续可见。

### 封面与作者

- **切换页面不再反复读取封面**：复用已加载的封面和图集图片，合并重复读取；图片来源变化时刷新，缓存受容量限制并在任务移除后释放。
- **缩略图铺满区域**：列表封面居中等比例填满容器，点击后仍可查看完整图片；原图保存和复制功能保留。
- **作者资料与本地作品搜索**：展示可用的作者或频道资料，点击作者可查找本地已有作品；不搜索平台内容。

### 细节修复

- 修复 Windows 桌面滚动条上下箭头的显示，保留原生点击滚动。
- 去掉平台筛选下划线、空列表重复边框和多余跳转按钮。
- 空分享链接提交改为顶部提示，不再占用页面空间。
- 优化小窗口下的列表、详情、文案与更新弹窗布局。

### 安装包

- Windows x64：`Yingqu_1.8.1_x64-setup.exe`
- macOS Intel：`Yingqu_1.8.1_x64.dmg`
- macOS Apple Silicon：`Yingqu_1.8.1_aarch64.dmg`

保留现有下载记录、本地文件和平台配置。Windows 安装包未配置代码签名，macOS 使用 ad-hoc 签名。
