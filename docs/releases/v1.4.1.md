本次更新调整 Windows 更新安装包的启动方式，处理点击“打开安装包”后程序异常退出、安装界面未出现的问题。

### 修复与改进

- **Windows 更新安装包**：完成文件校验后直接启动独立的安装器进程，避开原有的 Windows Shell 调用。应用不主动退出，启动失败时仍在更新弹窗显示错误。
- 保留打开前的文件类型、大小与 SHA-256 校验，支持含中文、空格和特殊字符的安装包路径。
- macOS 继续通过系统打开 DMG，安装方式保持不变。

### 安装包

- Windows x64：`Yingqu_1.4.1_x64-setup.exe`
- macOS Intel：`Yingqu_1.4.1_x64.dmg`
- macOS Apple Silicon：`Yingqu_1.4.1_aarch64.dmg`

如果旧版应用无法通过按钮打开安装包，可先从本页下载并手动运行。Windows 安装器在继续安装时可能要求关闭正在运行的旧版。
