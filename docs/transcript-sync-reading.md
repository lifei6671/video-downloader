# 视频与文案同步阅读（WB-305）

识别原文有已保存 `timing` 时默认显示同步阅读，支持段落跳转、播放跟随、自动滚动开关、键盘播放和连续段落选取。Windows 验证见[第二十三批](workbench-knowledge-base-validation.md#第二十三批wb-305-视频与文案同步阅读)；macOS Intel / Apple Silicon 继续待验收。

## 时间、来源与可用范围

直接读取 WB-302 的不可变文案版本及有序语音段，不从换行、字符数或播放进度推造时间。沿用媒体 PTS 零点，段落范围为 `[start_ms,end_ms)`，播放位置处于静音间隙或末端时不高亮任何段落。时间精度仍为 FSMN-VAD 语音段级，最长段落可能约 30 秒，不承诺句子、词或字的同步。

同步操作要求当前文件 ID 与文案一致，来源 Source 存在且与登记路径、大小、mtime 一致，文件未缺失或变化；文案切换读取期间禁用操作。不匹配时显示具体状态并保留全文阅读。旧原文没有 timing、整理稿和笔记继续使用原有正文界面，整理稿不会继承原文时间。

点击段落从其起点播放。首次请求创建来源绑定的播放器并带初始位置；同一普通视频会话复用播放器 seek，新的跳转取消尚未完成的旧 seek，切换文件 / 退出详情中止定位并释放媒体。已有片段播放切回同文件的完整视频会话后再定位，不被旧片段终点截断。

每次定位按实际 `seekable`、动态 duration 及探测的首帧下界检查起点，落点误差超过 50ms 明确反馈失败；不把正起点视频的 5 秒改成 0，也不将不可用范围截短成可播放范围。该容差是播放器可用性检查，不代表转录具有 50ms 语义精度或逐帧切割能力。

## 跟随、滚动与键盘

播放器通过已有 HTML media 的 timeupdate、seeked、play / pause 等事件发布时钟。阅读器二分查找当前段落，仅更新本地段落 / 播放状态，不在应用根部逐帧刷新，不增加定时轮询或后台服务。

自动滚动每次挂载默认开启，仅滚动文案内部容器；当前段落已在视野内时保持位置，不使用平滑动画或抢夺焦点。关闭后仍高亮当前段落，用户可自由滚动；重新开启回到当前段落。选取片段期间暂停自动滚动，保留开关状态。

“文案段落”区域可聚焦。焦点位于该区域或段落按钮时：Space 播放 / 暂停，上下方向键移动段落焦点，Enter 跳转或选取当前段落。未加载视频时播放动作先加载并定位；选取模式下播放不会改选区。输入框、全文阅读、整理稿、笔记、菜单及对话框沿原有键盘行为，不注册全局空格监听。段落可访问名称包含动作、序号、时间与正文；播放高亮不主动改变键盘焦点。

## 连续段落与片段收藏

“选取片段”进入范围选择，第一次点击设起始锚点，后续点击更新末端，反向选择同样得到连续范围；“取消选取”清除选择。选中范围显示真实起止时间并标记其中所有段落。

“收藏所选片段”打开已有片段编辑器，开始取第一段起点、结束取最后一段终点，原文引用为全部连续段正文以换行连接；绑定当时的 document ID / version 和 file ID。保留范围内的静音间隙，不拼接不连续视频。用户仍可填写标题、理由、调整范围和确认保存；草稿、离开保护、不可播放范围、Core 来源 / 引用校验沿 WB-303 执行，失败不会自动保存或截断时间。

“阅读全文”随时切回不可变原文，可选字引用笔记 / 片段、复制和导出全文；“同步阅读”返回段落界面。版本切换不把旧选区转移到新文案，普通刷新不会偷偷读取新版本。

本批仅增加前端交互，schema v6、逻辑备份 v4、engine 0.17.0 / JSONL v3 及 MCP 范围不变。没有重新运行 ASR、修改模型或新增第三方依赖。
